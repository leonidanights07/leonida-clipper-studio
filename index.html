How it works — and what it can't do

1. Upload your video file (and a second one if you have a separate facecam). 2. Pick a canvas size and a layout, drag the boxes where you want them, and set each box's source region. 3. Scrub the timeline and set In and Out. 4. Add a headline, a handle, and pick a subtitle style. 5. Export — the clip is cut in your browser and downloaded as an MP4.

Face tracking: per box, on or off. When on, the box's crop follows the detected face as the person moves — computed in your browser during export with MediaPipe (BlazeFace), no server. The preview does not track live; a tracked box shows a dashed pink border. If no face is found, the box stays still and the export still completes.

Modes: Game clipping defaults to game + facecam layouts; Podcast clipping defaults to the 50/50 speaker split and labels boxes SPK 1, SPK 2… The mode only changes defaults — every layout and box works in both modes, and you can add up to 4 boxes either way.

Subtitles: this site cannot transcribe speech by itself — that needs the local Python tool (Whisper) or a paid service, and this site has neither. Captions come from (a) subtitles already inside your video file, (b) an .srt/.vtt file you upload, or (c) words you type for the clip. If a clip has none of those, it exports with no subtitles.

YouTube links: not supported on this site. A link needs a server to fetch the video, and this site has no server. Use the free local Leonida Clipper Pro tool for YouTube links, then bring the file here — or cut it there directly.

Honest limits: you pick every moment yourself — nothing here finds the best moments for you (Leonida Clipper Pro does that automatically). Face tracking follows the face nearest each box's region and can lose it if the person leaves the frame or turns away. Export is slow in a browser (several minutes per clip). Videos over about 1 GB can be slow or run out of browser memory. And the tool does not grant permission to clip anyone's video: only use it on creators who have given permission to clip their videos.

First run loads the video cutter (about 30 MB) from the internet, so it can take a minute on a slow connection. After that, cutting happens on your device. Your video file is never uploaded anywhere.
